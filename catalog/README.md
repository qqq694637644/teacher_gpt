# Catalog

Version 3 runtime data is generated here after the complete textbook manifest is reviewed.

Expected files:

```text
catalog/dip4e/manifest.yaml
catalog/dip4e/compiled_locator_index.json
catalog/dip4e/validation_report.json
```

The application intentionally fails during startup until a complete, Version 3 compiled index exists. Partial indexes and Version 2 data are not accepted.
